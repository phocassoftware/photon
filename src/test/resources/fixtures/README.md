# Real Photon fixture

`andorra-release-260906.jsonl` contains a small, test-sized slice of the official Photon JSON
dump for Andorra. Its `Place` record preserves the source name, address, and coordinates from
the release snapshot dated 2026-09-06; the `CountryInfo` record is reduced to Andorra and the
English names needed by this test.

Source dump:

<https://download1.graphhopper.com/public/europe/andorra/photon-dump-andorra-release-260906.jsonl.zst>

Source MD5: `3a507bcaa42f15b446f14a577884b3bb`

(ODbL) 1.0. © OpenStreetMap contributors. This fixture is for tests only; it is not a complete
Photon database.
